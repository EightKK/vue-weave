# Code of conduct

## Expected behavior

Treat contributors and users with respect. Welcome different backgrounds and experience levels, give constructive feedback, and discuss technical decisions using evidence. Respect privacy and the boundaries of other participants.

Harassment, discriminatory language, threats, sexualized attention, personal attacks, impersonation and publication of another person's private information are unacceptable. Repeated disruption after a moderator asks it to stop is also unacceptable.

This policy applies to project issues, pull requests, discussions and other spaces operated by the project, and to conduct when someone is representing the project.

## Reporting

Report conduct problems through GitHub's reporting tools; the project has no separate contact address. Do not post incident details or personal information in public issues.

- To ask the project maintainers to moderate a comment, issue, pull request or discussion, report it from the content's **...** menu and choose **Report to repository admins**. Only repository maintainers see these reports.
- For abuse, spam or violations of GitHub's own policies, including conduct by a project maintainer, report the content to GitHub Support from the same menu, or [report abuse to GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

Include links to the content and the follow-up you are requesting.

## Enforcement

Repository maintainers moderate the spaces they operate. They may edit or remove harmful content, request a change in behavior, close a conversation, or temporarily or permanently restrict participation. They should consider context and severity, explain decisions privately where practical and protect the reporter's privacy. A maintainer with a conflict of interest should leave the report to another uninvolved maintainer where available. GitHub Support handles GitHub-policy reports separately from project moderation.

These responsibilities do not create a response-time or confidentiality guarantee beyond what the maintainer can provide. Changes to this policy should be documented publicly.
