# API リファレンス

このサイトの API リファレンスは、リポジトリにある手書きのドキュメントから作成中です。それらのドキュメントが正式な情報源で、npm パッケージにも含まれています。API の詳細な表は英語のままです。

- [Public API and input contracts](https://github.com/EightKK/vue-weave/blob/main/docs/api.md): すべてのコンポーネントのプロップ、イベント、スロット、公開メソッドと、すべてのコア関数。
- [Integration](https://github.com/EightKK/vue-weave/blob/main/docs/integration.md): Vue、Nuxt、独自の描画、テーマと `--vw-*` 変数、時間軸、保存。
- [Scheduling and resource load](https://github.com/EightKK/vue-weave/blob/main/docs/scheduling.md)。
- [Architecture, performance and scope](https://github.com/EightKK/vue-weave/blob/main/docs/architecture.md)。
