# グラフの組み込み

NetworkGraph を使ったアプリケーションの作り方を順に説明します。大きなグラフとタッチ操作、削除・コンテキストメニュー・ツールチップ、スナップとクリップボード、折りたためるグループとエッジのスタイル、スイムレーン、BPMN の業務フロー、数量フロー、ELK.js によるレイアウト、Mermaid・GraphML・draw.io のファイル、Worker でのレイアウト、小さなダイアグラムエディターです。使うプロップとイベントは [NetworkGraph](../components/network-graph.md) にあります。
