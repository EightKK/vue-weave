# API reference

The API reference of the site is being assembled from the hand-written documents in the repository, which remain the source of truth and ship in the npm package:

- [Public API and input contracts](https://github.com/EightKK/vue-weave/blob/main/docs/api.md): every component prop, event, slot and exposed method, and every core function.
- [Integration](https://github.com/EightKK/vue-weave/blob/main/docs/integration.md): Vue, Nuxt, custom rendering, themes and `--vw-*` variables, time scales and persistence.
- [Scheduling and resource load](https://github.com/EightKK/vue-weave/blob/main/docs/scheduling.md).
- [Architecture, performance and scope](https://github.com/EightKK/vue-weave/blob/main/docs/architecture.md).
